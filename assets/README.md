# Mascot sources

`mascot-original.jpg` is the approved character. `banner.jpg` is that same character with the EasyAgent wordmark. Both are the reference for the buddy.

`mascot.svg` is the measured trace of `mascot-original.jpg`, 42 cells wide and 44 tall. The grid is stored in `easyagent/mascot.py` and the SVG is generated from it. It is not a freehand redraw.

The mascot is locked. The grid, `mascot-original.jpg`, and `banner.jpg` do not change without maintainer approval.
